The extension includes Reagent, React, React DOM, the msgpackr codec, ClojureScript
and Google Closure Library runtime code. This folder retains the MIT notices for
Reagent/React/React DOM/msgpackr; ClojureScript and Closure notices are retained in
the compiled JavaScript. Neovim, the icon font, and pinned plugin notices are
retained under vendor/neovim, including license documents inside profile.json.

Original sources:
https://github.com/reagent-project/reagent
https://github.com/facebook/react
https://github.com/kriszyp/msgpackr
https://github.com/clojure/clojurescript
https://github.com/google/closure-library
https://github.com/neovim/neovim
